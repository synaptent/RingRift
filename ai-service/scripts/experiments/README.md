# AI Script Experiments

This directory is for active prototypes and investigative scripts that are not
part of RingRift's public proof path.

Promotion rule: a script here becomes supported only after it is listed in
[`docs/data/ai_surface_manifest.json`](/docs/data/ai_surface_manifest.json),
linked from a current runbook or reviewer doc, covered by a focused test or
gate, and explicit about canonical-vs-legacy data assumptions.
